# MineHelper

Клиентский Fabric-мод для Minecraft 26.1.2 с полезными функциями: **Block Finder** (поиск и подсветка блоков сквозь стены), **Player ESP** (подсветка игроков сквозь стены), **Auto Sprint** (автоматический спринт) и **Auto Clicker** (гуманизированный автокликер).

> **README in English:** [README.md](README.md)

**[⬇ Скачать последний релиз](https://github.com/markolockwood/MineHelper/releases/latest)**

## Предупреждение

Какие-то функции мода на некоторых серверах могут являться запрещёнными: либо не используйте их, либо не афишируйте использование.

## Возможности

### Block Finder

Хороший помощник для поиска нужной структуры, если вы знаете, какой блок в ней преобладает!

- Сканирует чанки вокруг игрока, используя палитру чанков — пропускает секции, которые точно не содержат нужный блок. Это делает поиск редких блоков (руды, глина, Ancient Debris) на порядки быстрее, чем перебор каждого блока
- Подсвечивает найденные блоки рамками настраиваемого цвета **сквозь стены**, используя кастомный `ALWAYS_PASS` depth-test pipeline
- Сканирование расходится от игрока, поэтому ближайшие блоки подсвечиваются в первую очередь
- Кэширует отсканированные чанки — повторно сканируются только новые области при перемещении
- Работает только на клиенте — не требует модификаций сервера, работает в одиночной игре и на любом сервере

### Player ESP

Система подсветки игроков с несколькими режимами отображения и поддержкой командных цветов:

- **Два режима отображения:**
  - **AABB** — лёгкая обводка по хитбоксу игрока (12 линий, ~в 5-10 раз легче, чем Glow)
  - **Glow** — полноценный vanilla-аутлайн с размытием, показывает реальную модель игрока и анимации сквозь стены
- **Два режима цвета:**
  - **Solid** — один настраиваемый цвет для всех игроков
  - **Team** — использует цвет команды игрока из scoreboard (например, красные против синих на серверах типа Hypixel)
- Настраиваемый радиус (16-256 блоков)
- Оба режима рендерятся сквозь стены без проверки глубины

### Auto Sprint

Автоматический спринт при движении вперёд — стандартная функция для удобства:

- Автоматически включает спринт при нажатии клавиши "вперёд"
- Проверяет условия: не в воде (если нет Dolphin's Grace), достаточно голода, не используется предмет, не присед
- Надёжнее ванильного toggle sprint (не сбрасывается после смерти/телепортов)
- **100% легально** на всех серверах — это стандартная vanilla-функциональность, сделанная более стабильной
- Включён по умолчанию, сохраняется между сессиями

### Auto Clicker

Гуманизированный автокликер для PvP и добычи:

- Автоматически кликает при зажатии левой кнопки мыши
- **Гуманизированный тайминг:** настраиваемый CPS (1-20, по умолчанию 10) с рандомизацией ±30%
- Использует ванильную логику атаки с обходом кулдауна для стабильной работы
- Работает в одиночной игре и на серверах
- Выключен по умолчанию
- **Внимание:** Используй ответственно — агрессивные настройки CPS могут вызвать срабатывание античита на некоторых серверах

## Установка

1. Установи [Fabric Loader 0.19.3+](https://fabricmc.net/use/)
2. Установи [Fabric API 0.155.2+26.1.2](https://modrinth.com/mod/fabric-api)
3. Скачай `minehelper-1.0.0.jar` из [последнего релиза](https://github.com/markolockwood/MineHelper/releases/latest) и помести его в `.minecraft/mods/`

## GUI

Доступ через команду `/minehelper`. Три вкладки:
- **General** — выбор языка, переключатель Auto Sprint, переключатель Auto Clicker с управлением CPS
- **Block Finder** — переключатель, целевой блок, радиус, цвет, толщина линий
- **Player ESP** — переключатель, режим отображения (AABB/Glow), режим цвета (Solid/Team), выбор цвета, радиус

## Команды

Все команды работают только на клиенте.

### Основные

| Команда | Описание |
|---|---|
| `/minehelper` | Открыть GUI со всеми настройками |
| `/minehelper lang <en\|ru>` | Переключить язык |

### Block Finder

| Команда | Описание |
|---|---|
| `/blockfinder set <block_id>` | Задать блок для поиска. Работает как `stone`, так и `minecraft:stone`. Автодополнение работает для всех блоков. |
| `/blockfinder check` | Показать название блока, на который ты смотришь |
| `/blockfinder toggle` | Включить / отключить сканирование |
| `/blockfinder clear` | Очистить кэш и пересканировать всё заново |
| `/blockfinder radius <16–128>` | Задать радиус сканирования в блоках (по умолчанию: 64) |
| `/blockfinder color <r> <g> <b>` | Задать цвет подсветки (0–255 на канал) |
| `/blockfinder status` | Показать текущее состояние: включён ли, целевой блок, найденные блоки, радиус |

**Горячая клавиша:** Назначь клавишу в `Управление → Разное → Toggle Block Finder`

**Примеры:**
```
/blockfinder set ancient_debris
/blockfinder toggle
/blockfinder color 255 165 0
/blockfinder radius 96
```

### Player ESP

| Команда | Описание |
|---|---|
| `/mhesp` или `/mhesp toggle` | Включить / отключить Player ESP |
| `/mhesp mode <aabb\|glow>` | Задать режим отображения (AABB: лёгкие рамки, Glow: vanilla-аутлайн с размытием) |
| `/mhesp colormode <solid\|team>` | Задать режим цвета (Solid: один цвет, Team: цвета команд) |
| `/mhesp color <r> <g> <b>` | Задать цвет для режима Solid (0–255 на канал) |
| `/mhesp radius <16–256>` | Задать радиус обнаружения в блоках (по умолчанию: 64) |
| `/mhesp debug` | Отладочная команда: показывает все доступные источники цвета для ближайших игроков |

**Примеры:**
```
/mhesp toggle
/mhesp mode glow
/mhesp colormode team
/mhesp radius 128
```

### Auto Sprint

| Команда | Описание |
|---|---|
| `/mhsprint` | Переключить Auto Sprint вкл/выкл |

### Auto Clicker

| Команда | Описание |
|---|---|
| `/mhclick` | Переключить Auto Clicker вкл/выкл |

**Примечание:** CPS настраивается через GUI во вкладке General (кнопки ±).

## Конфигурация

Настройки автоматически сохраняются в `.minecraft/config/`:

**`mh_blockfinder.json`:**
```json
{
  "scanRadius": 64,
  "highlightColor": [1.0, 1.0, 0.0, 1.0],
  "lineWidth": 3.0,
  "ticksPerScan": 2,
  "chunksPerScan": 8
}
```

| Поле | Описание |
|---|---|
| `scanRadius` | Радиус поиска в блоках (16–128) |
| `highlightColor` | RGBA, каждое значение от 0.0 до 1.0 |
| `lineWidth` | Толщина линий рамки |
| `ticksPerScan` | Тиков между шагами сканирования (увеличь, чтобы снизить нагрузку) |
| `chunksPerScan` | Чанков за один шаг сканирования (уменьши, чтобы снизить нагрузку) |

**`mh_playeresp.json`:**
```json
{
  "radius": 64,
  "lineWidth": 2.0,
  "renderMode": "AABB",
  "colorMode": "SOLID",
  "solidColor": [1.0, 0.0, 0.0, 1.0]
}
```

| Поле | Описание |
|---|---|
| `radius` | Радиус обнаружения в блоках (16–256) |
| `lineWidth` | Толщина линий для AABB режима |
| `renderMode` | `"AABB"` или `"GLOW"` |
| `colorMode` | `"SOLID"` или `"TEAM"` |
| `solidColor` | RGBA для режима Solid, каждое значение от 0.0 до 1.0 |

**`mh_autosprint.json`:**
```json
{
  "enabled": true
}
```

| Поле | Описание |
|---|---|
| `enabled` | Состояние Auto Sprint (true/false) |

**`mh_autoclicker.json`:**
```json
{
  "enabled": false,
  "cps": 10
}
```

| Поле | Описание |
|---|---|
| `enabled` | Состояние Auto Clicker (true/false) |
| `cps` | Кликов в секунду (1–20, с рандомизацией ±30%) |
